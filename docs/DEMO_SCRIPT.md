# 群证 2–3 分钟演示脚本

## 0:00–0:20｜说明需求

“群面很难独自练习，普通练习结束后也很难复核自己做得怎样。群证把多人群面模拟、证据型复盘和可验证的训练摘要放进同一条流程。”

## 0:20–0:45｜选场景和题目

选择行业、填写公司名称、选择目标岗位和对应题型。强调题目来自预设题库，分类沿用求职岗位场景，不依赖临时生成或 Monad 专属题目。

## 0:45–1:25｜展示群面

开始短题目演示，展示 AI 候选人、面试官、阶段倒计时和用户发言。说明语音不可用时可以继续纯文字练习。

## 1:25–1:55｜查看证据型复盘

展示综合分、维度分、发言证据与改进建议。点击一条证据定位到原始发言，说明分数可追溯到训练过程。

## 1:55–2:30｜发布能力凭证

展开“查看上链字段”，说明原始对话、公司名和报告正文留在链下。勾选公开字段确认，连接钱包并切换到 Monad Testnet，签名一次 `issueCredential` 交易。

## 2:30–2:50｜核验结果

展示交易确认状态、Token ID 和 Monadscan 交易链接。用下载的 JSON 证明文件说明如何复算 score hash。

## 演示边界

- 真实发布前，确认合约已部署、合约地址已配置、钱包测试网有测试币。
- 网络失败时展示实际错误和本地保存路径，不展示假交易。
- 不声称 LLM 在 Monad 上运行，也不将训练分数描述成职业资格或企业认证。
